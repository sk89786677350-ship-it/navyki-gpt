# Навыки GPT

Реестр навыков Codex, доступных на Lenovo по состоянию на 16 октября 2026 года. Навыки установлены локально для этой учётной записи; публикация этого реестра на GitHub сама по себе не устанавливает их на другой компьютер.

Этот репозиторий содержит только перечень и ссылки на первоисточники. Исходные файлы сторонних навыков, локальные пути, ключи доступа и данные проектов сюда не копируются.

## Установлено

| Направление | Навыки | Назначение |
| --- | --- | --- |
| Интервью | `discovery-interview-prep`, `ux-discovery-interviewer` | Подготовка исследования и проведение UX-интервью |
| Дизайн | `ui-ux-pro-max`, `frontend-design` | Проектирование интерфейсов и визуальное оформление |
| Сайт и каталог | `fullstack-engineer`, `database-engineer`, `data-engineer`, `qa-engineer`, `security-engineer`, `devops` | Разработка сайта, работа с данными, проверка, защита и развёртывание |
| Клиентские AI-агенты | `ai-engineer`, `prompt-engineer`, `llm-tester` | Архитектура агентов, инструкции для моделей и проверка ответов |
| Видео | `remotion-best-practices` | Сборка анимации, роликов, субтитров и вывод видео через Remotion |

Дополнительно доступны системный `imagegen` для изображений и персонажей, а также плагин **Superpowers** версии `6.4.2` с 15 навыками рабочего процесса. Инструмент Higgsfield доступен отдельно; его стоимость и условия проверяются перед конкретным видеопроектом.

## Важные ограничения

- Отдельно установленные навыки Forgewright содержат ссылки на общие правила и инструменты полного набора. Полная среда Forgewright не устанавливалась; часть её механизмов потребует дополнительной настройки в проекте.
- У репозитория Forgewright не обнаружена общая лицензия. Его файлы здесь не публикуются. Право на включение исходного кода или материалов автора в коммерческий продукт следует проверять отдельно.
- У `ui-ux-pro-max` на Lenovo локально адаптирован путь к поисковому скрипту. При восстановлении на другом компьютере путь нужно настроить заново.
- Установка навыков не подключала платные API, видеосервисы или движок Remotion. [Условия использования Remotion](https://www.remotion.dev/docs/license/pricing) зависят от размера команды и способа применения.

При работе с заказами, артикулами и остатками необходимо брать актуальную таблицу склада и сопоставлять товары по точным артикулам.
