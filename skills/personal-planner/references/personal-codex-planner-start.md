# Запуск личного планировщика в Codex

1. Выбери папку, которой управляешь, для личного планирования.
2. Если нужны локальные записи, скопируй туда файлы из personal-planner-folder-template. Замени шаблон даты на фактическую; неизвестные сведения оставь как «не заполнено».
3. Открой выбранную папку как рабочую в Codex и попроси спланировать личные дела или день.
4. Долговременные файлы обновляются только после команды «сохрани», «сохрани глобально» или явного согласия на предложенную запись.
5. Для ChatGPT открой отдельный личный чат и вставь полный промпт. Установка навыка Codex не устанавливает навык в аккаунт ChatGPT и не открывает ему доступ к папке Codex. Для переноса используй сводку вручную, если нет разрешённого средства передачи.

Это переносимая инструкция: она не выбирает папку, не заполняет личные записи и не настраивает напоминания.
