# Папка личного планировщика

Эта папка предназначена для личного планирования. Цели, проекты, задачи и расписание не предполагаются заранее.

## Файлы
- AGENTS.md — локальная область и правила работы.
- MEMORY.md — подтверждённые предпочтения и личный контекст.
- GOALS.md — согласованные цели и ограничения.
- PROJECTS.md — личные проекты.
- memory/YYYY-MM-DD.md — записи по датам.

Открой эту папку как рабочую в Codex, чтобы начать. ChatGPT не получает эти файлы автоматически; при необходимости переноси сводку вручную.
